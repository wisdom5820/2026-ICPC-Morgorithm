# 2026 ICPC - Morgorithm

ICPC 준비를 위한 팀 레포지토리입니다.

## 📌 협업 규칙

### 문제 풀이
- 각자 자신의 브랜치에서 문제를 풀이합니다.
- 풀이 코드는 `problems/플랫폼/` 폴더에 업로드합니다.
- 파일명은 `문제번호_문제이름.cpp` 형식을 사용합니다.

### GitHub
1. 문제 풀이 전 최신 `main` 브랜치를 받아옵니다.
2. 자신의 브랜치에서 문제를 풀이합니다.
3. 풀이가 완료되면 커밋 및 Push합니다.
4. `main` 브랜치로 Pull Request를 생성합니다.
5. 다른 팀원이 코드를 확인하고 리뷰합니다.
6. 리뷰가 끝나면 `main`에 Merge합니다.

### 코드 리뷰
- 최소 1명의 팀원이 코드를 확인합니다.
- 다른 풀이 방법이 있다면 PR에 공유합니다.
- 이해되지 않는 코드는 서로 질문합니다.
